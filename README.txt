یه فونت فارسی/عربی رو اینجا بذار تا خروجی «کارت تصویری» فعال بشه.
پیشنهاد: فونت رایگان Vazirmatn (وزیرمتن) - نسخه‌ی Bold
دانلود از: https://github.com/rastikerdar/vazirmatn/releases
فایل مورد نیاز رو با نام Vazirmatn-Bold.ttf همین‌جا کپی کن،
یا مسیرش رو با متغیر محیطی FONT_PATH مشخص کن.

اگه این فایل رو نذاری، ربات همچنان کار می‌کنه ولی به‌جای کارت تصویری،
نتیجه رو به‌صورت متن معمولی می‌فرسته.
